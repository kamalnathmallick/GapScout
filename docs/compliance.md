# Compliance & Legal Guide

This document outlines GapScout's compliance architecture, legal considerations under India's Digital Personal Data Protection Act (DPDP Act, 2023), risks associated with Google Maps scraping, and instructions on how to switch to the official Google Places API.

---

## 1. India's Digital Personal Data Protection Act (DPDP Act 2023)

GapScout is engineered strictly as a B2B market intelligence and lead ranking system. Under the DPDP Act 2023 and global privacy frameworks (such as GDPR), data processing must adhere to strict principles of purpose limitation, data minimisation, and consent.

### Key Tenets in GapScout:

1. **Public Business Data Exemption & Limitation:**
   - GapScout only collects and indexes **publicly available business information** (e.g. registered shop names, public business categories, commercial store addresses, and publicly advertised business phones/websites).
   - Under Section 3(c)(ii) of the DPDP Act, personal data made publicly available by the data principal is distinguished from private personal data. GapScout enforces a strict **Field-Level Allow-List** (`app.cleaning.allow_list`) that discards private metadata, personal reviewer emails, and personal identifiers.

2. **Data Minimisation & Retention:**
   - Raw scraped dumps containing extraneous session data are strictly retained for a maximum of **90 days** (configurable per workspace).
   - An automated daily Celery task (`gapscout.cleanup_expired_raw_data_task`) purges raw scraped payloads (`place.raw = {}`) older than the retention window, preserving only the normalised public attributes.

3. **Data Principal Rights (Access, Portability & Erasure):**
   - **Full Account Export:** Workspaces can download their complete data archive in structured JSON or tabular CSV at any time (`GET /api/v1/account/export`).
   - **Right to Erasure ("Delete My Data"):** Workspaces can permanently delete all associated jobs, places, leads, drafts, and users with a cascading deletion flow (`DELETE /api/v1/account/data`).

4. **Do-Not-Contact (DNC) & Mandatory Opt-Outs:**
   - The platform strictly enforces a **Do-Not-Contact list** across all channels. Any prospect who requests opt-out is permanently flagged, immediately halting draft generation (`DNCBlockedError`).
   - Every outreach draft generated by the system includes a mandatory opt-out notice:
     - Cold email: *"Reply STOP or unsubscribe to not hear from us again."*
     - Direct message / WhatsApp: *"Reply STOP to opt out."*

## 2. Google Terms of Service & Scraping Risks

### Terms of Service Considerations
Google Maps Terms of Service explicitly prohibit automated scraping, indexing, or bulk extraction of Google Maps content without explicit written permission.

### Risk Management & Safety Measures:
- **Scraping Notice & Explicit User Consent:** Every new search job presents a clear compliance notice requiring explicit user acknowledgment of Google's Terms of Service risks before initiating scans.
- **Global Polite Delays & Rate Limiting:** All scraper requests incorporate polite delays with randomized jitter (1.0s to 2.0s) and concurrency caps to prevent aggressive bursting.
- **Zero Automated Outreach:** GapScout **never** sends automated emails, SMS, or chat messages. All outreach messages are purely generated as drafts for human review, verification, and manual dispatch.
- **Untrusted Data Isolation:** All scraped text is treated as passive, untrusted data wrapped in defensive XML tags (`<untrusted_scraped_data>`) to protect against prompt injection.

## 3. Switching to the Official Google Places API

For commercial production deployments requiring complete adherence to Google's terms, GapScout provides a pluggable data provider architecture through the `DataSourceProvider` interface (`app/providers/base.py`).

### Step 1: Obtain a Google Maps Platform API Key
1. Visit the [Google Cloud Console](https://console.cloud.google.com/).
2. Enable the **Places API (New)** and **Geocoding API**.
3. Create an API Key and restrict it to Places API and your server's outbound IP addresses.

### Step 2: Implement the Google Places Provider
Create `apps/api/app/providers/google_places.py` conforming to `DataSourceProvider`:

```python
import httpx
from app.providers.base import DataSourceProvider, RawPlace, PlaceDTO, SearchOptions

class GooglePlacesAPIProvider(DataSourceProvider):
    def __init__(self, api_key: str):
        self.api_key = api_key
        self.base_url = "https://places.googleapis.com/v1"

    @property
    def name(self) -> str:
        return "google_places_official"

    def search(self, category: str, area_or_cell: str, options: SearchOptions | None = None) -> list[RawPlace]:
        headers = {
            "Content-Type": "application/json",
            "X-Goog-Api-Key": self.api_key,
            "X-Goog-FieldMask": "places.id,places.displayName,places.primaryType,places.formattedAddress,places.location,places.rating,places.userRatingCount,places.nationalPhoneNumber,places.websiteUri"
        }
        body = {
            "textQuery": f"{category} in {area_or_cell}",
            "maxResultCount": 20
        }
        if options and options.lat and options.lon:
            body["locationBias"] = {
                "circle": {
                    "center": {"latitude": options.lat, "longitude": options.lon},
                    "radius": float(options.radius or 1000)
                }
            }
        resp = httpx.post(f"{self.base_url}/places:searchText", json=body, headers=headers, timeout=30.0)
        resp.raise_for_status()
        places = resp.json().get("places", [])
        return [
            RawPlace(provider=self.name, provider_place_id=p["id"], data=p)
            for p in places
        ]

    def to_place_dto(self, raw: RawPlace) -> PlaceDTO:
        d = raw.data
        return PlaceDTO(
            provider=self.name,
            provider_place_id=raw.provider_place_id,
            name=d.get("displayName", {}).get("text", "Unknown"),
            category=d.get("primaryType"),
            address=d.get("formattedAddress"),
            phone=d.get("nationalPhoneNumber"),
            website=d.get("websiteUri"),
            rating=d.get("rating"),
            review_count=d.get("userRatingCount", 0),
            latitude=d.get("location", {}).get("latitude"),
            longitude=d.get("location", {}).get("longitude"),
            raw=d
        )
```

### Step 3: Configure Settings & Provider Factory
1. Add `GOOGLE_MAPS_API_KEY` to `.env` and `app/config.py`.
2. Update `_get_provider` in `app/tasks.py`:
   ```python
   if name == "google_places_official":
       return GooglePlacesAPIProvider(api_key=settings.google_maps_api_key)
   ```
3. Set `DEFAULT_DATA_SOURCE_PROVIDER=google_places_official` in environment variables.
