# GapScout: Portfolio & Engineering Highlights

## 5 Resume Bullets (Impact-Oriented & Quantified)

1. **Distributed Spatial Intelligence Engine:** Architected a map-based market analytics platform in **Python 3.11, FastAPI, PostGIS, and Uber H3**, optimizing hexagonal tiling computations across 50,000+ local points of interest to complete in under 7.5 seconds (< 30s benchmark) and sub-80ms GeoJSON API response times for 5,000 hexes.
2. **Two-Stage Active Learning ML Pipeline:** Built a self-improving lead scoring system combining deterministic 5-factor rule heuristics with a calibrated **HistGradientBoosting / Logistic Regression** tournament in **scikit-learn** and **SHAP**, boosting precision@10 by 1.6x through time-series feature snapshots and 14-day outcome window tracking.
3. **Enterprise Human-in-the-Loop AI Outreach:** Developed a grounded LLM outreach workflow using **Claude 3.5 Sonnet / Haiku** with strict length limits ($\le 120$ words email, $\le 450$ chars WhatsApp) and zero hallucination constraints, neutralizing indirect prompt injection via `<untrusted_content>` quarantine tags.
4. **Resilient Asynchronous Grid Orchestration:** Designed an idempotent distributed task pipeline with **Celery and Redis**, integrating open-source containerized scrapers with rate limiting, polite backoffs, and automated 90-day raw data retention pruning.
5. **Modern Full-Stack Cloud Architecture:** Built an interactive **Next.js (App Router), TypeScript, Tailwind, deck.gl, and MapLibre GL** frontend with strict multi-tenant isolation, achieving 88% backend test coverage (350+ unit/contract/eval tests) and automated GitHub Actions CI/CD pipelines.
